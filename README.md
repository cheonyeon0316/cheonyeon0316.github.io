# cheonyeon0316.github.io

GitHub Pages 허브입니다. 이 저장소의 `docs/` 아래에 정적 프로젝트를 추가하면 한 사이트에서 공개할 수 있습니다.

## 프로젝트 추가

1. `docs/projects/<project-slug>/` 폴더를 만들고 그 안에 `index.html`을 둡니다.
2. `docs/index.html`에 프로젝트 링크를 추가합니다.
3. `main` 브랜치에 푸시하면 GitHub Pages가 `docs/` 내용을 자동 게시합니다.

프로젝트 주소는 `https://cheonyeon0316.github.io/projects/<project-slug>/` 형태입니다.

## 배포

GitHub Pages의 게시 원본은 `main` 브랜치의 `/docs` 폴더입니다. Pages 설정은 **Deploy from a branch**를 사용합니다.
