# Jelly Dash 아트 방향

## 캡처에서 읽은 스타일

- **화면 구성:** 캐릭터는 화면 왼쪽 아래에 고정되고, 젤리와 장애물은 오른쪽에서 들어오는 횡스크롤 러너입니다. 중앙 플레이 공간은 넓고, 점수와 진행 정보는 가장자리 HUD에 모여 있습니다.
- **색:** 동굴은 짙은 남보라와 자주색을 바탕으로 하고, 수정과 발판에는 청록·하늘색 발광을 씁니다. 분홍과 금색은 아이템과 보상에 사용해 어두운 배경에서 잘 보이게 합니다.
- **재질과 형태:** 캐릭터와 아이템은 모서리가 둥글고 통통한 형태입니다. 표면은 매끈하고 윤기가 나며, 가장자리 하이라이트와 부드러운 발광으로 깊이를 줍니다. 표정은 큰 눈과 단순한 입으로 읽기 쉽게 표현합니다.
- **플레이 신호:** 낮은 장애물은 점프로 넘고, 머리 높이의 장애물은 슬라이드로 피합니다. 밝은 젤리를 모아 공격 게이지를 채우고, 준비되면 전방 장애물을 공격합니다.

캡처의 팔레트와 렌더링 인상을 참고해 새 캐릭터와 배경을 제작했습니다. 원본 게임의 캐릭터, 로고, UI 이미지를 복제하지 않았습니다. 장애물과 공격은 같은 팔레트의 SVG 에셋으로 구성하고 기존 점프·슬라이드 판정에 연결했습니다.

달리기는 생성된 아틀라스와 `manifest.json`의 프레임 좌표·FPS를 읽어 플레이 중 재생합니다. 준비 화면과 점프 중에는 정지 스프라이트를 사용하고, 슬라이드 중에는 전용 슬라이드 스프라이트를 사용합니다.

## 가독성 조정

- 밝은 동굴 배경 위에 남색 투명막과 가장자리 비네팅을 더해 화면 전체 명도를 낮췄습니다.
- 트랙은 짙은 보라색으로 분리하고, 청록색 레일과 자주색 보조선으로 주행 경계를 강조했습니다.
- 캐릭터에는 자주색 외곽 발광을 적용해 수정 배경과 분리했습니다. 수집 아이템과 공격은 청록·분홍 하이라이트를 유지해 플레이 신호가 묻히지 않게 했습니다.
